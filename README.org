#+title: README

* Overview
This is a simple audio player written using C and miniaudio. It plays locally downloaded tracks.

This was an experiment to understand miniaudio's high-level API and get a feel for integration with Emacs.

It is relieving to have a simple player within the Emacs environment, and stay in flow without context switching to a browser and anti-privacy streaming platforms.

* Features
- Load playlist folder and play all tracks in it
- Skip current song
- Add any number of playlists and tracks in a folder
- Run program and select desired playlist to play
- Integrate into Emacs

* Getting started

** 1. Create a playlists folder and download music
You should have a directory called playlists, and within them, a folder for each playlist. Then, download tracks within each playlist folder.

** 2. Build
#+NAME: build
#+BEGIN_SRC bash
  git clone https://github.com/flowy-live/local-audio-player 
  cd local-audio-player

  gcc main.c -o play -ldl -lpthread -lm # linux compilation, modify for macos / windows
#+END_SRC

** 3. Setup Emacs
Modify the hardcoded paths in player.el to your built executable & playlists folder.

src_bash{cp ./player.el ~/.emacs.d/}

Add the following to your `.emacs`:
#+BEGIN_SRC lisp
(add-to-list 'load-path (expand-file-name "~/.emacs.d"))
(require 'player)

; optional
(global-set-key (kbd "C-c n p") #'player-start)
```
#+END_SRC

Run src_lisp{M-x eval-buffer} to evaluate lisp expressions in player.el.

Usage:
- src_lisp{M-x player-start} (you will be prompted for which playlist to begin playing)
- src_lisp{M-x player-next} (or 'n' within player buffer mode)
- src_lisp{M-x player-quit} (or 'q' within player buffer mode)
